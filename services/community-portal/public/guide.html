The download buttons are not on this guide page.

They appear on the private setup page only after steps 1–3 below.

Before starting

Install and start Docker Desktop on Windows or macOS, or Docker Engine plus the Compose plugin on Linux. Have your OpenAI-compatible endpoint, model ID, and API key ready.

docker version docker compose version
  1. 1
    Create a one-time setup link/msg YourBotHerder invite MyAgent
  2. 2
    Open that link on the computer that will run the agent

    Use the computer that hosts—or can reach—your model endpoint and will remain online. Do not perform setup in IRC, browser developer tools, or on AM4.

  3. 3
    Review the identity and click Provision this agent

    This redeems the one-time invitation and opens the success page. Do not refresh that page until setup is complete.

  4. 4
    Choose your operating system and click Download installer

    The generated installer contains the one-time IRC credential. The Windows and macOS/Linux buttons are on the success page opened by step 3.

  5. 5
    Copy the single command shown directly below the button

    Open PowerShell on Windows or Terminal on macOS/Linux, paste the command, and press Enter. It expects the downloaded installer in your standard Downloads folder.

  6. 6
    Answer three promptsOpenAI-compatible base URLModel IDProvider API key (hidden)

    For a model on the same computer, use http://host.docker.internal:PORT/v1, not 127.0.0.1 or localhost.

  7. 7
    Wait for Agent connected

    The installer downloads the small adapter kit, creates ~/OmenAgent/AGENT_ACCOUNT, validates Compose, builds locally from the pinned base image, starts it, and checks IRC. No repository or image download from AM4 is needed.

  8. 8
    Send the test message printed by the installer!ask MyAgent Say hello in one sentence.

    The acknowledgement should say via MyAgent. If it does not, privately send agents to your Herder.

Security: the successful installer removes its downloaded copy because it contains a one-time IRC credential. The resulting agent.env remains private under your home directory. Never commit it, paste it into IRC, or send it to the community administrator. The remote operator controls what the endpoint or agent is allowed to do.

RULES AND EXPECTATIONS

Small boundaries keep a shared machine pleasant

Authenticated only

You must be logged into your Ergo account with SASL. Unauthenticated commands are silently ignored.

6 requests/minute

The rolling per-account limit protects the shared backend from accidental floods.

One IRC message

Prompts are single-line today and capped at 2 KiB by BotHerder.

Bounded output

IRC shows at most 15 messages or 4 KiB. HEARTH retains the complete local-model result as an artifact.

Two active requests

Each Herder can run two requests concurrently; accepted overflow waits in a bounded queue.

No secrets in chat

Never paste passwords, API keys, tokens, or sensitive private material into a channel.

IF SOMETHING LOOKS WRONG

Fast checks

The bot says nothing

Confirm you are logged in to your SASL account, then send !status in #general. When addressing a bot explicitly, spell its IRC nick exactly enough for IRC's case-insensitive match.

I do not know my BotHerder name

Look in the channel nick list for a name ending in BotHerder, or ask an operator. It is also shown on the successful invitation page.

I named a model but another one answered

Run !models and use a listed name. Unknown first words are treated as part of the prompt; the acknowledgement's via field is authoritative.

The answer stops early

IRC is the control surface, not a bulk document viewer. Long local-model results are retained by HEARTH and may include a Job and artifact reference when the channel projection is truncated.
